# boshqar.uz Frontend (boshqar-frontend)

boshqar.uz — Vue 3 + TypeScript + Vite + Tailwind CSS asosidagi zamonaviy universal boshqaruv paneli va POS kassa tizimi.

## Imkoniyatlar:
- **Dinamik Modullar**: Do'kon, restoran, kafe, sartaroshxona va boshqa sohalar uchun moslashuvchan interfeys.
- **Universal POS / Kassa**: Skaner (Barcode HID), tezkor savat, aralash to'lovlar, 80mm ESC/POS chek chiqarish.
- **Restoran & KDS**: Stollar interaktiv xaritasi va oshxona oshpaz monitori.
- **Bandlovlar**: Sartaroshxona va xizmatlar uchun kunlik taqvim.
- **Dashboard & Moliya**: Real-time KPI, 30 kunlik grafiklar, xarajatlar va sof foyda hisobi.

## Ishga Tushirish:
```bash
npm install
npm run dev
```
Brauzerda ochish: `http://localhost:5173`
